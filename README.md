# 🔐 Network Security Chatbot

An intelligent **Network Security Chatbot** built using **Python** and **Flask** that provides answers to cybersecurity-related questions and includes interactive quiz features to enhance user learning.

---

## 🚀 Features

* 💬 Answer cybersecurity and network security questions
* 🧠 Interactive quiz system for learning
* ⚡ Fast and simple web interface
* 🌐 Deployed using Replit
* 📚 Pre-defined Q&A knowledge base

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS
* **Backend:** Python (Flask)
* **Deployment:** Replit

## ▶️ How to Run Locally

1. Clone the repository

```
git clone https://github.com/your-username/network-security-chatbot.git
```

2. Navigate to the project folder

```
cd network-security-chatbot
```

3. Install dependencies

```
pip install flask
```

4. Run the application

```
python main.py
```

5. Open in browser

```
http://localhost:5000
```
